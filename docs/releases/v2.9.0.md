# Release Specification: Para v2.9.0

**Milestone Commit #300 — Academic Gamification, 80 Automated Achievements & Student Portal**

---

## 🚀 Overview

**Para v2.9.0** marks the historic **300th commit milestone** of the Para distributed academic ecosystem. This release brings comprehensive gamification to all 26 students of college group **1-КПД-3**, converting real-world attendance, homework, and bot telemetry into experience points (XP), ranks, and badges.

Crucially, v2.9.0 establishes **strict role-based UI isolation** in the Telegram Mini App: classmates see an engaging, modern Cyberpunk-themed Student Portal, while developer/tester tools (Swagger UI and Jaeger Traces) are completely invisible and strictly guarded against unauthorized inspection.

## 🔒 Security Architecture: Developer Menu Isolation

To ensure students are never exposed to developer tooling:
1. **Default DOM State**: `#tab-swagger` and `#tab-jaeger` have `style="display:none !important;"` in HTML and CSS.
2. **Client-side Guard**: `switchTab()` checks `if ((tab === 'swagger' || tab === 'jaeger') && !isTester) return;`.
3. **Cryptographic Validation**: When the Mini App opens, `POST /miniapp/auth` sends Telegram `initData`. The backend validates the bot HMAC-SHA256 signature and checks `is_tester_allowed(user_id)`.
4. **Backend Security Gate**: `/openapi.json` and `/jaeger/*` enforce FastAPI `verify_api_or_tester` dependencies; direct HTTP requests return `401 Unauthorized` / `403 Forbidden`.
