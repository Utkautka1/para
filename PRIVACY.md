# 🔒 Политика конфиденциальности (Privacy Policy)

**Дата вступления в силу:** 5 октября 2026 г.  
**Проект:** Телеграм-бот и сервисы учебной группы 1-КПД-3 («para»)  
**Репозиторий:** [https://github.com/Utkautka1/para](https://github.com/Utkautka1/para)

---

## 1. Общие положения

1.1. Настоящая Политика конфиденциальности определяет порядок сбора, обработки, хранения и защиты информации о пользователях (студентах, старостах и преподавателях), взаимодействующих с Telegram-ботом, внутренним API и сопутствующими сервисами группы 1-КПД-3 (далее — «Сервис»).  
1.2. Сервис создан исключительно в академических и организационных целях для координации учебного процесса студентов колледжа КТМУ (СПбГУПТД).  
1.3. Использование Сервиса означает полное и безоговорочное согласие пользователя с условиями настоящей Политики конфиденциальности.

---

## 2. Какие данные обрабатываются

Сервис обрабатывает только минимально необходимый объем данных для обеспечения учебных функций:

1. **Идентификаторы Telegram:**
   - Уникальный числовой идентификатор (`user_id`).
   - Имя пользователя (`username`) и отображаемое имя профиля (`first_name`, `last_name`).
   - Используются для проверки принадлежности пользователя к списку студентов группы (авторизация через белый список).

2. **Академические данные и посещаемость:**
   - Отметки присутствия на парах («П» — присутствовал, «О» / «1 оп» — опоздал, «У» — уважительная причина / справка, «Н» — отсутствовал).
   - Номер академической подгруппы (1 или 2 подгруппа).
   - Данные фиксируются старостой группы и синхронизируются с ведомостью на Яндекс Диске по протоколу WOPI.

3. **Даты рождения:**
   - Дата рождения (день и месяц) студентов группы для публикации праздничных поздравлений в учебном топике в 07:00 МСК.

4. **Материалы заданий (при использовании авторешения ДЗ):**
   - Фотографии и текстовые формулировки учебных задач, добровольно отправляемые студентом боту.
   - Файлы используются однократно для распознавания и генерации отчета по ГОСТ 7.32-2017 и удаляются после завершения задачи.

---

## 3. Цели обработки данных

Обработка данных осуществляется строго в следующих целях:
- **Авторизация и безопасность:** ограничение доступа к закрытым академическим ресурсам группы только для подтвержденных студентов.
- **Информирование об учебном процессе:** выдача актуального расписания пар, звонков, зачетов и экзаменов.
- **Ведение учета посещаемости:** автоматизированный сбор сведений старостой, формирование рейтинга групп и дашборда академических лиг.
- **Самообслуживание студентов:** предоставление студенту приватной сводки его посещаемости через команду `/my_attendance`.
- **Вспомогательные академические сервисы:** напоминания о начале занятий, праздничные поздравления и помощь в подготовке отчетов.

---

## 4. Хранение данных и безопасность

4.1. Данные хранятся в изолированном контуре на сервере проекта:
   - Оперативные данные, очереди задач и сессии хранятся в оперативной памяти Redis с ограниченным временем жизни (TTL).
   - Справочники (реестр одногруппников, дни рождения) хранятся в локальных конфигурационных JSON-файлах с ограниченными правами доступа (`chmod 600`).  
4.2. Сервис применяет многоуровневую защиту:
   - Авторизация запросов к внутреннему API по криптографическому ключу `X-API-Key`.
   - Защита от спама и перегрузок через middleware ограничения частоты запросов (Throttling).
   - Передача данных в Telegram защищена протоколом MTProto / HTTPS.

---

## 5. Взаимодействие со сторонними сервисами

Сервис взаимодействует со сторонними платформами исключительно в рамках заявленной функциональности:
- **Telegram Bot API:** доставка входящих и исходящих сообщений, документов и уведомлений.
- **Яндекс 360 / Яндекс Документы:** синхронизация электронной таблицы посещаемости старосты по защищенному протоколу WOPI.
- **DeepSeek API:** обработка текста и изображений учебных задач при запросе студентом помощи с решением ДЗ (запросы выполняются в режиме `stateless` без сохранения контекста диалога).

Сервис **не передает**, **не продает** и **не раскрывает** персональные данные рекламным трекерам, маркетинговым сетям или любым коммерческим третьим лицам.

---

## 6. Права пользователя и удаление данных

Каждый студент группы имеет право:
- Получить информацию о хранящихся в отношении него данных (включая личную статистику посещаемости по команде `/my_attendance`).
- Запросить корректировку своего Telegram ID, юзернейма или даты рождения через старосту или администратора бота.
- Отозвать согласие на получение персональных рассылок или запросить удаление своего Telegram ID из базы авторизации.
